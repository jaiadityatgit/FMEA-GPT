# 10. Create structured formula extraction

Create something such as:

```text
src/rag/formula_extractor.py
```

The implementation must preserve both:

```text
display representation
```

and:

```text
machine representation
```

For example:

```text
display:
Cm = β × α × λp × t

machine:
{
  "name": "mode_criticality_number",
  "expression": "beta * alpha * lambda_p * t",
  "variables": ["beta", "alpha", "lambda_p", "t"],
  "units": "...",
  "source_document": "...",
  "page_number": ...
}
```

Do NOT invent units.

Do NOT infer missing variable definitions.
