# FMEA-GPT | Aerospace Safety & Airworthiness Reasoning Engine

FMEA-GPT is an advanced Failure Mode and Effects Analysis (FMEA) reasoning engine designed specifically for the aerospace and aviation sectors. Built upon a robust RAG (Retrieval-Augmented Generation) architecture, it ingests and grounds its reasoning in strict regulatory standards and engineering frameworks (e.g., FAA AC 25.1309, EASA CS-25, MIL-STD-1629A, NASA guidelines).

The platform features a precision-engineered frontend that mirrors high-end aerospace MRO (Maintenance, Repair, and Overhaul) workstations, and a Python/FastAPI backend utilizing LangGraph for highly auditable, multi-step failure analysis.

---

## 🚀 Key Features

- **Regulatory Grounding**: Uses a tightly scoped ChromaDB vector store (`fmea_aerospace_knowledge_core_final`) comprising 2,234 domain-specific aerospace chunks.
- **Epistemic Reasoning Engine**: Powered by a multi-node LangGraph trace, guaranteeing auditable logic for component failure propagation and criticality scoring.
- **Traceability & Provenance**: Every failure claim generated by the system is cross-referenced with exact source documentation, eliminating hallucinations.
- **Aerospace UI/UX**: Designed for engineers, the frontend emphasizes high data density, precision instrumentation aesthetics, and stark industrial visuals—stripping away standard generic AI chatbot interfaces.

---

## 🛠️ Architecture Overview

- **Frontend**: React + Vite, heavily styled with custom vanilla CSS (`index.css`) to match strict aerospace operational guidelines.
- **Backend**: FastAPI, serving the core inference endpoints.
- **Agentic Engine**: LangGraph handles stateful, multi-phase logic mapping (Phase 5A Epistemic Model).
- **Vector Database**: Pre-ingested ChromaDB.
- **Test Suite**: 134 strict assertions running under `pytest` to ensure 100% adherence to safety guidelines and architecture integrity.

## 🏁 Getting Started

### Prerequisites
- Node.js (v18+)
- Python 3.10+
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/jaiadityatgit/FMEA-GPT.git
cd FMEA-GPT
```

### 2. Backend Setup
Create a virtual environment and install the required dependencies:
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Mac/Linux: source venv/bin/activate

pip install -r requirements.txt
```
*(Ensure you have configured any required environment variables for your specific LLM provider if utilizing an external synthesizer.)*

Start the FastAPI server:
```bash
cd src
uvicorn server.main:app --reload --port 8000
```

### 3. Frontend Setup
Open a new terminal window and navigate to the frontend directory:
```bash
cd frontend
npm install
npm run dev
```
Access the dashboard at `http://localhost:5173`.
